# check_tor visual style

The icon is an open onion outline with two short shoots, two curved layers on the
left, and a bold checkmark on the right. It identifies the project; scan results
continue to use the scanner's existing text labels.

These are suggested defaults for consistent presentation, not additional
conditions on reuse of the artwork.

## Assets

All artwork lives in `assets/branding/`.

| Asset | Suggested use |
| --- | --- |
| `check-tor.svg` | Navy icon with a transparent background; the editable master. |
| `check-tor-reverse.svg` | Pale mint icon with a transparent background, for dark surfaces. |
| `check-tor-on-mint.svg` | Navy icon on a pale mint square. |
| `check-tor-mono.svg` | Black icon with a transparent background. |
| `check-tor-128.png`, `check-tor-512.png` | Transparent navy exports for ordinary reuse. |
| `check-tor-on-mint-512.png`, `check-tor-reverse-512.png` | Ready-to-use mint tile and dark-background exports. |

## Color and placement

| Color | Value | Role |
| --- | --- | --- |
| Ink blue | `#173B6C` | Primary mark and optional heading accent. |
| Pale mint | `#E8F7F0` | Background or reversed mark. |
| Black | `#000000` | Monochrome reproduction. |

Use the supplied canvas padding, preserve the proportions, and leave room around
the shoots. For the README, a left-aligned icon around 96 pixels wide is enough.
Keep the project name as `check_tor` in the document's existing typography.

Prefer the navy version on light backgrounds and the pale mint version on dark
backgrounds. Use the full design at 32 pixels or larger when the inner layers
need to remain clear. At 16 pixels, those fine details become faint; a future
favicon would benefit from a separately reviewed small-size variant. The shape
should carry the meaning without requiring a particular color distinction.

Suggested alt text: **check_tor logo: an onion outline with a checkmark**. When
an icon is purely decorative beside an equivalent accessible label, empty alt
text may be more appropriate.
